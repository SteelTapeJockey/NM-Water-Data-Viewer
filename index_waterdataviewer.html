How to use this app
Follow the tabs left to right: this guide, then Sources to find and add data, then Active Layers to style it and view stats.
  1. Browse Sources. The Sources tab groups data sources into categories by type — Water, Minerals & Geology, Municipal & Local Government, and so on. Each category holds several sources, and each source is a single REST/WMS/WFS/OGC API endpoint published by a different agency — federal, state, local government, a university, or a nonprofit. Hover any source for a note on what it actually contains.
  2. Expand a source and tick layers. Click a source to open it and see its individual layers or feature types. Check the box next to any layer to add it to the map — you can check as many layers from as many sources as you want at once; they all stack together.
  3. Switch to Active Layers. Once something's added, open the Active Layers tab. From there you can adjust opacity, open 🎨 Style to change color/size or symbolize by category or numeric bins, and open Σ Stats for counts, histograms, and category breakdowns of whatever's currently on screen.
⚠️ About exporting data
This app doesn't download or export the underlying data itself. What you can export is the list of source URLs you're using — "Export all sources" or "Export selected sources" in the header — as a JSON file. Paste any of those URLs into a desktop GIS program (ArcGIS Pro, QGIS) or the agency's own web map, and use that software's normal query/select/export tools to pull the actual data.
One exception: the Water Quality Portal layer's popups link directly to a CSV download, since that specific source publishes its own public download API.
Filtering Draw a polygon, or upload a GeoJSON boundary, to limit every active layer — and its stats — to one area.

📍 Spatial filter (area of interest)
Limit every layer — and its stats — to one area. Draw a shape on the map, or upload a GeoJSON polygon to use as the boundary.
— or —
Point data (CSV or GeoJSON points) is added as a map layer. A GeoJSON polygon can instead be used as your spatial filter boundary — you'll be asked which you want.
